AI Task Assistant — Project Overview

AI Task Assistant is a smart task‑management system designed to demonstrate modern QA Technical skills across UI, API, AI endpoints, SQL validation, automation, and documentation.

The application allows users to:
- Create tasks
- Edit tasks
- Mark tasks as completed
- Delete tasks
- View task lists

Additionally, the system integrates AI features to enhance task management:

- Summarize long task descriptions
- Improve unclear descriptions
- Classify tasks (work, personal, urgent, etc.)
- Suggest priority levels

This project showcases a complete QA workflow using real tools, real APIs, and real automation.



Objectives
- Demonstrate QA Technical Fullstack capabilities
- Test UI flows using Cypress
- Test API CRUD operations using Postman
- Validate AI endpoints (summarize, classify, priority, rewrite)
- Validate data using SQL queries
- Document the system using User Stories, Acceptance Criteria, Test Cases, and Bug Reports
- Provide evidence of all testing activities

Architecture Overview
The system consists of:

- UI: RealWorld App (React)
- API CRUD: GoRest public API
- AI Endpoints: Groq / OpenAI / HuggingFace API
- Database: Local SQLite or PostgreSQL dataset
- Automation: Cypress
- API Testing: Postman + Newman
- Documentation: Markdown files
